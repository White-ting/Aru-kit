## 这是什么

Aru 里的 AI 平时只有你开口它才说话。这套东西让它能"注意到"你在干什么，在合适的时候**自己决定**要不要来找你：

```
iPhone 快捷指令（打小报告：打开了什么 App、到了哪、睡了醒了）
      ↓
守门人（放在你自己的 Cloudflare 上，记下来，按规则判断值不值得叫醒 TA）
      ↓  值得的话，写一份简报，加密
你电脑上的 Aru Host（只当门铃，看不到内容）
      ↓
Aru 里的 TA 被叫醒，读完简报，自己决定说不说、说什么
```

- 大多数时候守门人只是记一笔，不会叫醒 TA。
- 叫醒了，TA 也可以**选择不说话**（实测过：TA 判断"现在没必要打扰她"，就安静待着，只在自己的记录里写了为什么）。
- 你的作息、位置这些数据只存在**你自己的** Cloudflare 账号里；送进 Aru 的简报全程加密。

现在守门人会叫醒 TA 的情况（都能改）：

- 凌晨 1～5 点还在打开 App；
- 到达或离开你指定的地方（比如医院）；
- 某个 App 一口气用了超过 120 分钟（退出那一刻判断）；
- 你在快捷指令里点了「想聊天」（第 9 步，可选）。

还可以让守门人知道你**现在的状态**：在工作、想一个人待着、手机快没电了、刚下班（第 9 步，可选）。在工作、开着勿扰、说了想独处的时候，平常的关心先不叫，等你忙完；到了医院这种要紧的地方照叫。很久没动静、下班这两种，默认先只记下来，看几天准不准再决定要不要叫。

规则管不到的（"差一点"、"今天跟平时不一样"），可以再接一个**小模型**替 TA 看一眼（第 7 步，可选）。它只说叫不叫和为什么，不跟你说话。

几条底线不管怎样都守：你在睡觉不叫（熬夜那条除外）、一天最多 5 次、两次之间至少隔 60 分钟、熬夜一夜只叫一次。

## 需要准备

| 东西 | 说明 |
|---|---|
| iPhone + Aru | Aru 是 TestFlight 版，要能在「协作者 → 主动」里看到「外部触发」 |
| 一台常开的电脑 | 装 Aru Host（Windows、Mac、Linux 都行）。电脑关机或睡着时，TA 不会被叫醒，但不会丢东西 |
| Cloudflare 账号 | 免费的就够。用邮箱在 dash.cloudflare.com 注册 |
| 一个域名 | 几块钱一年那种就行（.top 之类）。**在国内强烈建议要**：Cloudflare 默认给的 `workers.dev` 地址在国内基本打不开 |

> ⚠️ 全程**只用一个 Cloudflare 账号**。域名、隧道、守门人必须在同一个账号里。登录后看左上角的账号名，每一步都确认一下没切错。

> 💡 **进阶：不想自己一步步点，可以让 AI 全权代做 Cloudflare 这部分。** 如果你在用能跑命令的 AI（比如 Claude Code），可以在 Cloudflare 里建一个 **API 令牌**（右上角头像 → 我的个人资料 → API 令牌 → 创建令牌）交给它，下面第 2、4 步在 Cloudflare 上的事（建隧道、建 D1 数据库、建 Worker 贴代码、填密钥、绑域名、设定时）它都能替你做完，你只管看结果。有几件还是要你自己动手：第 1 步去域名注册商改域名服务器、Cloudflare 的邮箱验证和第一次进 Zero Trust 起团队名、电脑上装 cloudflared（Windows 要点管理员确认）、Aru 里配对和导出发送凭证、第 6 步手机上的快捷指令。
> - 令牌只勾要用的权限（Workers 脚本、D1、Workers 路由、DNS、Cloudflare Tunnel 这几项的「编辑」），账号和域名都限定成你自己那一个。
> - 令牌等于你账号的钥匙：存成电脑上的一个文件让 AI 去读，别直接贴进聊天；别交给你不信任的 AI 或别人。
> - 做完了回 API 令牌页把它删掉，以后要改再建一个。不放心的话，顺手把管理口令、事件口令也换一遍（快捷指令里的跟着改）。
> - 隧道安装时那串长长的安装令牌是另一把钥匙，同样别贴进聊天、别截图。

## 第 1 步：把域名交给 Cloudflare 管

1. 登录 Cloudflare → **添加域名**（Add a domain / Add a site）→ 填域名本身（不带 www，不带 https），比如 `abc.top`。
2. 下面"扫描现有记录"保持勾选 → 继续 → 套餐选最下面的 **Free（免费）** → 继续。
3. 页面会给你两个地址，长得像 `xxx.ns.cloudflare.com`。**每个人的都不一样，以你页面上的为准**。
4. 去你买域名的地方（阿里云、腾讯云、雨云……）→ 找到这个域名 → 管理 → **DNS 服务器 / 修改 DNS**，把原来的换成这两个，保存。
5. 回 Cloudflare，点 **检查域名服务器**。几分钟到几小时后，域名旁边显示 **Active（有效）** 就好了。

注意：
- 页面上有一条"请确保 DNSSEC 已关闭"，是给所有人看的通用提醒。新买的域名一般本来就是关着的，不用管。
- **只在一个账号里加一次**。以后 Cloudflare 再提示"去注册商改域名服务器"，先停下来问人，别直接改。改错了，已经在用的东西会全断。

## 第 2 步：让手机在外面也能连上你电脑的 Host

先在电脑上装好 Aru Host，用手机扫码配对。（Host 的下载和配对见 [aru-host](https://github.com/Aevella/aru-host) 的说明。）

### 2.1 Windows 先放行防火墙

Aru Host 首页如果写着"防火墙还没放行局域网访问"：

1. 点「放行防火墙」，弹窗点"是"；
2. 要是报错没成功：在左下角 Windows 图标上**右键 → Windows PowerShell（管理员）**，粘贴下面这行，回车：
   ```
   New-NetFirewallRule -DisplayName 'Aru Host (home)' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8787 -Profile Private,Domain
   ```
3. 再点右下角 Wi-Fi 图标 → 当前 Wi-Fi 的「属性」→ 网络配置文件选 **专用**。

### 2.2 建隧道（给 Host 一个公网 HTTPS 地址）

1. Cloudflare → **Zero Trust**（第一次进要起个团队名，选免费套餐）→ **网络 Networks → Tunnels → 创建隧道** → 选 **Cloudflared** → 名字随便，比如 `aru-host`。
2. 系统选 **Windows**、**64 位**，下载页面给的 `.msi` 装好。
3. 开始菜单搜 `cmd` → 右键 **以管理员身份运行**，把页面上那条 `cloudflared.exe service install eyJ……` 粘进去，回车。
   - 以前在别的账号装过隧道的，先跑一次 `cloudflared.exe service uninstall`，再装新的。
4. 页面下方显示**已连接**后点下一步，填公共主机名：
   - **子域名**：比如 `aru`
   - **域**：选你的域名
   - **服务 URL**：`http://localhost:8787`（前面要写 `http://`，**不是** https；8787 是 Host 默认端口）
5. 保存。手机浏览器打开 `https://aru.你的域名/.well-known/aru.json`，能看到一段文字就通了。

### 2.3 告诉 Host 这个地址

电脑上 Aru Host → 总览 → **地址设置 / 手机远程连接** → 连接方式选 **公网 HTTPS** → 填 `https://aru.你的域名`（后面什么都别加）→ 检查连接 → **保存连接地址**。

然后手机连上**跟电脑同一个 Wi-Fi**，打开 Aru 里这台 Host 的总览，点「检查」。连接线路里多出一条 HTTPS 的，以后用流量也能连了。

> Aru Host 要 **0.36.0 或更新**，Windows 版才有填 HTTPS 地址的地方。

## 第 3 步：在 Aru 里建一个「外部触发器」

1. Aru → 打开你的**协作者** → **主动** → 上面切到 **外部触发**。
2. 新外部触发器：
   - **名称**：起个正式点的，比如「她那边有动静」。**别带"测试"两个字**，TA 会看到这个名字，叫"测试"的话真有事它也会以为是测试。
   - **接收事件的 Host**：选你的电脑；
   - **投递方式**：**自动触发**（"正文作为事件背景唤醒协作者，不显示成你的发言"）；
   - **在哪条对话里说**：跟随最新对话。
3. 创建，然后导出**发送凭证**。它是一段 `{ ... }` 文字，里面有地址、口令和钥匙。
   - ⚠️ **这段凭证等于你家门钥匙**：拿到它的人能往你的 Aru 里塞消息。**别截图、别发群、别发给任何人**，复制好直接粘到第 4 步。
   - 万一泄露了：新建一个触发器，换上新凭证，再把旧触发器删掉，旧的就作废了。

## 第 4 步：搭守门人

### 4.1 准备两个口令

口令就是一串别人猜不到的字母数字。最简单的办法是自己乱敲 30 个左右的**字母和数字**（别用 `+ & # 空格` 这些符号）。

想让电脑帮你生成的话，在 PowerShell 里跑这行（注意是 PowerShell，不是黑色的 cmd；在 cmd 里先输入 `powershell` 回车也行）：
```
[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
```

准备**两串**，记在记事本里：
- **事件口令**：给快捷指令用；
- **管理口令**：给你自己开管理页用。

### 4.2 建数据库

Cloudflare → **存储和数据库 → D1** → 创建数据库 → 名字 `knock` → 创建。

### 4.3 建 Worker、贴代码

1. **计算 → Workers 和 Pages** → 创建 → 从 **Hello World** 开始 → 名字 `knock` → 部署。
2. 点 **编辑代码（Edit code）** → 左边代码区点一下 → **Ctrl+A 全选、删掉** → 粘贴守门人代码 `worker.js` 的全部内容。
   - `worker.js` 就在原版压缩包里，跟这份教程放在一起：右键 → 打开方式 → 记事本，Ctrl+A 全选、Ctrl+C 复制。
   - 手上只有这份教程、没有 `worker.js`：说明你拿到的是被转出来的，去找给你教程的人要原版压缩包。**别让 AI 照着教程自己写一份**，写出来的跟管理页、快捷指令对不上。
3. 点右上角蓝色的 **部署（Deploy）**。

> 怎么确认贴的是新版：在编辑器里按 Ctrl+F 搜 `事件口令不对`，搜得到就是新版。贴完一定点 **Deploy**，不然线上还是旧的。

### 4.4 接数据库

`knock` 页面 → **设置 Settings → 绑定 Bindings → 添加 → D1 数据库**：
- **变量名**：`DB`（大写，就这两个字母）
- **数据库**：选 `knock`

> 浏览器开了自动翻译的话，页面上可能显示成"数据库""敲"，那是翻译的，实际值没问题。建议对这个网站关掉翻译，免得填英文名字时被改掉。

### 4.5 三个密钥

**设置 → 变量和机密（Variables and Secrets）→ 添加**，类型选 **Secret（密钥）**，加三个。**名字照抄，一个字母都不能错**：

| 名字 | 值 |
|---|---|
| `EVENT_TOKEN` | 事件口令 |
| `ADMIN_TOKEN` | 管理口令 |
| `WAKE_BUNDLE` | 第 3 步导出的整段凭证，从 `{` 到 `}` 全部 |

每加一个点 **Deploy**。⚠️ **"Save version" 只是存草稿，不生效**，要点 Deploy。

### 4.6 换成你自己的域名

`knock` 页面上面一排标签里点 **域名（Domains）→ 添加域名** → 填 `knock.你的域名` → 一路点到确认。

- 输入框里**已经自动带着域名**的话，只在前面打 `knock`。打完整的就会叠成 `knock.abc.top.abc.top`，加完看一眼列表里的名字对不对。
- 要是跳出一个大窗口，问你"搜索、AI 爬虫、训练"要不要拦，说明**这个账号里没有你的域名**（多半是账号切错了），先别继续，回去检查第 1 步加在了哪个账号。
- 加完等一两分钟，证书自动配好。

### 4.7 打开管理页、测试敲门

浏览器打开：
```
https://knock.你的域名/#key=管理口令
```
（中间是 **`#`**，不是 `?`。`#` 后面的口令不会发到服务器、不进 Cloudflare 的记录；页面打开后会自己把它从地址栏去掉，只在这个标签页里记着，关掉就忘。不带口令打开也行，页面会让你粘贴一次。）
- 能看到「knock 守门人」和一大段设置，就成了；
- 点 **测试敲门**，下面应该显示"已敲门（Aru 外部触发 …）"，Aru 里的 TA 会收到一条（测试的那份简报会写明"这是测试"，TA 多半会回一句或者选择不打扰）。

这个带口令的网址等于钥匙，存成书签，别发出去。

### 4.8 定时清理旧记录（建议做）

`knock` → **设置 → 触发事件（Trigger events）→ Cron 触发器 → 添加** → 填 `*/30 * * * *`（每 30 分钟跑一次）→ 保存。守门人会把 14 天以前的报告删掉；第 7 步的小模型、第 9 步的下班确认和"很久没动静"也靠它定时查。不加的话记录会一直留着。

> 以前照旧版教程填过 `17 * * * *` 的，改成 `*/30 * * * *`。

## 第 5 步：叫醒说明（管理页里那段设置）

管理页最上面的大框就是"叫醒说明"。第一次打开时，守门人已经在里面放好了一份默认的，照下面的表改数字和开关就行，改完点 **保存**。每一项的意思：

| 项 | 意思 |
|---|---|
| `note` | **用 TA 的口气写的一句话**：TA 在意你什么、是什么脾气。会原样放进简报里，醒来的 TA 读到会觉得"这是我交代过的" |
| `daily_cap` | 一天最多叫醒几次 |
| `cooldown_min` | 两次叫醒至少隔几分钟 |
| `late_night` | 几点到几点还在开 App 算熬夜（`from` 1、`to` 5 就是凌晨 1～5 点） |
| `places.watch` | 到达或离开这些地方会叫醒，写地点名，跟快捷指令里填的 `place` 对得上就行（写"医院"，`市第一人民医院` 也能对上） |
| `long_session` | 连着刷手机超过 `minutes` 分钟算太久。`apps` 空着就是所有 App 都算，填 `["小红书"]` 就只算小红书。`gap_min`（默认 5）：关掉一个 App、这么多分钟内又打开下一个，算同一段，几个 App 来回切也接得上；填 0 就只算单个 App。`once`（默认 `true`）：同一段只敲一次，放下手机超过 `gap_min` 分钟、重新开始一段才再算；填 `false` 就是冷却过了接着敲 |
| `model` | 小模型，见第 7 步。不开就让 `enabled` 保持 `false` |
| `mood` | 心情（第 9 步）：点了「想独处」后 `alone_hours` 小时内平常的关心都不叫；`request` 是 `true` 时点「想聊天」直接叫醒 TA，冷却只算 `cooldown_min` 分钟（每天上限照样算）；选的心情 `keep_hours` 小时内会写进简报 |
| `inactivity` | 很久没动静：`from`～`to` 点之间，隔了 `hours` 小时一条打开 App、到达离开的报告都没有。每天从 `from` 点重新算起，早上不会把一整夜当成没动静。`wake` 是 `false` 时只记在管理页，不叫醒 |
| `work_end` | 下班（第 9 步）：工作专注模式关掉、`confirm_min` 分钟内没再打开就算下班。`wake` 是 `false` 时只记下，不叫醒 |

改的时候只改数字和引号里面的字，**逗号、引号、括号别动**。保存时提示"格式不对"，就是哪里少了个逗号或引号。

> 想马上试一次"刷太久"：把 `minutes` 改成 `1`，保存，刷一分多钟小红书再退出来。**试完记得改回去**。

## 第 6 步：iPhone 快捷指令（打小报告）

以 iOS 26 为例，版本不同按钮的字可能差一两个。

### 6.1 打开小红书时上报

1. 打开 **快捷指令** → 底部的 **自动化** 标签（底部标签栏缩成一小条的话先点一下展开）→ 右上角 **＋**。
   > 别在"新建快捷指令"里搜"自动化"，那里搜不到。自动化是底部的一个标签。
2. 在触发方式列表里选 **App** → 选 **小红书** → 只勾 **已打开** → 选 **立即运行**，关掉"运行时通知" → **下一步**。
3. 点 **创建新快捷指令**（或"新建空白自动化"）→ **添加操作** → 搜 **URL** → 选 **获取 URL 的内容**。
4. 点蓝色的 URL，填 `https://knock.你的域名/event`。
5. 点这个动作旁边的展开箭头，填：
   - **方法**：POST
   - **头部** → 添加新头部：键 `Authorization`，值 `Bearer 事件口令`（`Bearer` 后面**空一格**，口令从记事本粘贴）
   - **请求体**：JSON → 添加新字段 → 文本：
     - `type` ＝ `app_open`
     - `app` ＝ `小红书`（**直接打字**，别用"快捷指令输入"这种蓝色变量）
6. 点右下角 ▶ 试运行。下面出现 `"ok": true` 就成功了（`"wake": false` 是正常的：现在不是凌晨，只记一笔）。
7. 右上角 ✓ 保存。

### 6.2 关掉小红书时上报（算时长要用）

建一条新的自动化，别直接复制上一条，复制的偶尔会带进看不见的字符：
- 触发：App → 小红书 → 只勾 **已关闭** → 立即运行；
- 动作一样，只把 `type` 改成 `app_close`，`app` 还是 `小红书`（**跟打开那条写得一模一样**）。

"已打开"和"已关闭"**别勾在同一条里**，不然守门人分不清是开还是关。

### 6.3 其他可以加的

| 想报告什么 | 触发方式 | `type` | 再加的字段 |
|---|---|---|---|
| 到了某地 | 到达 → 选地点 | `arrive` | `place` ＝ 地点名 |
| 离开某地 | 离开 → 选地点 | `leave` | `place` ＝ 地点名 |
| 去睡了 | 睡眠 → 就寝开始（或专注模式"睡眠"打开时） | `sleep` | 不用 |
| 起床了 | 睡眠 → 醒来（或闹钟停止时） | `wake_up` | 不用 |
| 开始充电 | 充电器 → 已连接 | `charge_start` | 不用 |
| 电量低、在工作、心情 | 见第 9 步 | | |

"到达/离开"第一次用会要定位权限，选"始终允许"。

### 6.4 看报告有没有到

管理页往下拉，**「最近 6 小时收到的事」**里每一行就是一条报告，最新的在最上面。页面不会自己刷新，要手动刷新。

**看一眼名字带上了没有**：应该是 `app_open 小红书`、`app_close 小红书`。只有 `app_open` 后面没有名字（管理页会标红写"没带 App 名字"），就是请求体里少了 `app` 那一行，或者值用了蓝色变量。回 6.1 第 5 步改成直接打字。名字对不上的话，"刷太久"那条就算不准。

> 一条自动化里勾了好几个 App（"打开 A、B、C 任一时"）的，没法告诉守门人到底开的是哪个。想算时长，就给每个 App 单独建"打开""关掉"两条，名字写死。
**「叫醒记录」**里是真正敲过门的记录，被底线挡下的也记在这里，后面写着原因。

## 第 7 步：接小模型（可选，建议做）

上面那几条规则很死板：凌晨 1 点算熬夜，0 点 50 就不算；刷 120 分钟算太久，110 分钟就不算；"今天一整天都不太对劲"更是写不成规则。

小模型就是补这个的：**它替 TA 看一眼你手机上的动静，判断"这时候 TA 会不会想找你"**。

- **什么时候看**：白天每 30 分钟看一次；另外，某件事"差一点"碰到规则时也会看（比如刷了规则时长的六成以上、熬夜规则前一个小时还在用、到了一个不在关注列表里的地方）。
- **它看什么**：TA 写的那句 `note`，你今天的大概（几点起床、每个 App 开了几次、待了多久、去过哪），最近两小时的动静，上次叫醒是什么时候、为什么。
- **它能做什么**：只能说"叫"或"不叫"，再加一句理由。**它不跟你说话，也不替 TA 说话**。它说叫，也照样要过底线（睡觉、每天上限、冷却），而且它自己每天还有一个更小的上限（默认 2 次）。它的理由会写进简报，TA 醒来能看到"守门人的小模型看了觉得——……"。
- **都看得见**：管理页「小模型」那一栏，记着它每次看了以后说叫还是不叫、为什么。

默认用的是 Cloudflare 自己的 **Workers AI**：不用另外注册、不用钥匙，你的动静不会发去别家公司（留存照 Cloudflare 的条款）。它有每天的免费额度，一天看几十次只用掉很小一部分（以 Cloudflare 页面上的为准）。默认的模型是谷歌的 Gemma 4（`@cf/google/gemma-4-26b-a4b-it`）。

> **2026-11-20 起，原来默认的通义千问被 Cloudflare 下架了。** 以前的版本默认用 `@cf/qwen/qwen3-30b-a3b-fp8`，Cloudflare 从 2026-11-20 起不再回答它（公告：developers.cloudflare.com/changelog/post/2026-11-05-planned-model-deprecations/）。症状是管理页「小模型」那一栏每次都是"出错"，后面多半带着 `410`、`5028` 或 `Gone` 这样的字。
>
> **已经装好的，要换新代码**：照 4.3 换上新版 `worker.js`（v2.2.2 或更新），点 **Deploy**，再点「现在问它一次」，显示想叫或不叫就好了。叫醒说明里的 `"name"` 要是空着就不用管；要是填着原来那个千问的名字，改回空的 `""`。
>
> 光在旧代码里把 `"name"` 换成新模型**不行**：新模型会先想一大段再回答，旧代码给的字数不够，它想完了还没写答案，就一直报"小模型没回 JSON"。新代码会让它少想或不想。
>
> 想要中文更好的，可以把 `"name"` 填成 `"@cf/qwen/qwen3.8-27b"`（Cloudflare 推荐的另一个小模型）。它想得更细，但花的额度是 Gemma 4 的十几倍，免费额度用得快些。

### 7.1 换上新代码

照 4.3 把 `worker.js` 换成新版，点 **Deploy**。

> 怎么确认是新版：在编辑器里按 Ctrl+F 搜 `小模型`，搜得到就对了。

### 7.2 接上 Workers AI

`knock` 页面 → **设置 Settings → 绑定 Bindings → 添加 → Workers AI**：
- **变量名**：`AI`（大写，就这两个字母）

保存，点 **Deploy**。

### 7.3 定时改成每 30 分钟

照 4.8 做；做过的，把 `17 * * * *` 改成 `*/30 * * * *`。

### 7.4 在管理页打开它

管理页「叫醒说明」大框里找到 `"model"` 那一行，把 `"enabled": false` 改成 `"enabled": true`，点 **保存**。其他几项：

| 项 | 意思 |
|---|---|
| `style` | 它的性子：`少叫`（默认，拿不准就不叫）、`适中`（跟 TA 交代过的话沾边就叫）、`多叫`（有一点迹象就叫，靠冷却和上限兜着）。只改引号里的两个字 |
| `every_min` | 白天隔几分钟看一次（Cron 是 30 分钟一跑，所以写比 30 小没用） |
| `from`、`to` | 几点到几点之间才定时看（`9`、`23` 就是早上 9 点到晚上 11 点）。夜里交给熬夜规则 |
| `daily_cap` | 小模型一天最多叫醒几次（在总的 `daily_cap` 之内） |
| `name` | 空着就用默认的模型（Gemma 4），一般不用改。也可以填 Cloudflare 上别的文字模型名（`@cf/` 开头），见第 7 步开头那段 |

### 7.5 问它一次试试

管理页「小模型」那一栏 → **现在问它一次（不会真的敲门）**。

几秒后会显示 **想叫** 或 **不叫**，后面跟一句理由。这只是问问，不会真的敲门，可以随便点。

- 显示"出错：没绑定 Workers AI" → 7.2 没做，或者变量名不是 `AI`、没点 Deploy。
- 显示"出错：小模型没回 JSON" → 偶尔会这样，再点一次；总是这样的话截图问人。
- 显示"出错"，后面带 `410`、`5028` 或 `Gone` → 用的模型被 Cloudflare 下架了，照第 7 步开头那段换。

> 它一直说「不叫」是正常的：默认性子是「少叫」，平常刷手机它不会叫。想让它更敢叫，先把 7.6 的 `note` 写好（它最看这句话），还嫌保守就把 `style` 改成 `适中` 或 `多叫`。

### 7.6 把 `note` 写好

`note` 是 TA 写给守门人的一段话，用在两个地方：

1. **小模型判断时最看重它**：照着这段话想"这时候 TA 会不会想找她"。
2. **每次叫醒都原样放进简报**：开头写着"你之前交代我的：……"，TA 醒来读到，会觉得这是自己交代过的。

**最好让 TA 自己写。** 把下面这段发给 Aru 里的 TA：

> 我给你搭了一个守门人。它看着我手机上的动静（打开了什么 App、待了多久、到了哪、几点睡几点起），觉得你可能想找我的时候，就把你叫醒，递一份简报给你，找不找我由你决定。守门人里还有一个小模型，规则管不到的时候它替你看一眼要不要叫你。
> 请你用你自己的口气，写一段给守门人的话（200 字以内），告诉它：
> 1. 什么时候一定叫你（比如你担心我的那些情况）；
> 2. 什么时候别叫你（我哪些习惯是正常的，不用大惊小怪）；
> 3. 你希望它怎么拿捏，宁可少叫还是宁可多叫。
> 写的时候别用英文双引号，要引用就用「」。

写出来大概像这样：

> 她一个人闷着刷手机刷很久的时候叫我，那多半是心情不好。半夜一两点还醒着叫我。她去医院、去陌生地方的时候叫我。上班时间、周末早上赖床刷手机是正常的，别叫。宁可少叫，别让她觉得被盯着。

越具体越好，尤其是"什么时候别叫"：小模型最怕不知道哪些对你来说是正常的。

**贴进管理页时注意：**

- 找到 `"note": ""` 这一行，把 TA 写的话贴进**两个引号中间**；
- 整段要在**一行**里：TA 写了好几段的话，把换行删掉连成一段；
- 话里不能有英文双引号 `"`，有的话换成「」。

点「保存」，显示"保存好了"就成了。提示"格式不对"，多半是混进了英文双引号或换行。贴完可以再点一次「现在问它一次」，看小模型的理由是不是开始照着 TA 的话在想了。

### 7.7 （可选）不用 Workers AI，换成别家的模型

想用 DeepSeek、阿里百炼这类有 OpenAI 兼容接口的模型，在 4.5 的地方再加两个 Secret：

| 名字 | 值 |
|---|---|
| `LLM_URL` | 那家的 chat/completions 地址，比如 `https://api.deepseek.com/chat/completions` |
| `LLM_KEY` | 那家的 API 钥匙 |

再在叫醒说明里把 `"name"` 填成那家的模型名（照那家的文档写）。设了 `LLM_URL` 就不再用 Workers AI。

> 注意：这样做，你的动静记录会发到那家公司的服务器去判断。用 Workers AI 的话只交给 Cloudflare。

## 第 8 步：真的叫醒一次试试

管理页的「测试敲门」送的简报写明"这是测试"，TA 知道不是真的。想看 TA 被**真的**叫醒时怎么反应，可以临时把一条规则调得很容易碰上。

### 8.1 用"刷太久"那条

1. 管理页「叫醒说明」里找到 `"long_session"`，把 `"minutes": 120` 改成 `"minutes": 1`，保存。
2. 打开小红书（做了"打开"和"关掉"两条快捷指令的那个 App），刷 **2 分钟以上**，退出来。
3. 退出那一刻守门人会真的敲门。回管理页刷新，「叫醒记录」最上面多一条 `long_session`，写着"已敲门"。
4. 去 Aru 里看 TA 怎么反应。
5. **测完一定改回 `"minutes": 120`，保存**，不然以后刷两分钟就叫一次。

想再测一次：同一段只敲一次（`once`），要先放下手机 **5 分钟以上**（`gap_min`）再从第 2 步开始；不然守门人当你还在同一段里刷，不会再敲。

### 8.2 想让 TA 更容易开口：用"熬夜"那条

"刷了 2 分钟"TA 多半觉得不算事、选择不说。换成熬夜更像 TA 会在意的：

1. 把 `"late_night"` 的 `"from"` 改成现在的钟点、`"to"` 改成下一个钟点（比如下午 3 点多就填 `15` 和 `16`），保存。
2. 打开小红书。简报上会写"15:30 还在用「小红书」"。
3. **测完改回 `1` 和 `5`，保存。**

### 要先知道的

- **TA 可能不说话**：这不是坏了，是 TA 在自己决定。叫醒记录写着"已敲门"就说明门敲到了。想知道 TA 怎么想的，事后在 Aru 里问 TA："刚才守门人叫过你吗？你怎么想的？"
- **可能被底线挡下**：离上一次**真的**叫醒不到 60 分钟（测试敲门不算）、今天已经叫满 5 次、快捷指令报过"就寝"还没报"起床"——这几种，叫醒记录会写"挡下：……"和原因。
- **只弹通知、对话里没消息**：新版 Aru 有人遇到过，原因还在查。点开通知看看，再截图来问。

## 第 9 步：让守门人知道你现在的状态（可选）

做完这一步，守门人会多知道几件事：手机快没电了、你在工作（或开着勿扰、睡眠）、你自己点的心情、你下班了。它们大多**不会叫醒 TA**，只是让守门人更会挑时候：

- 开着**工作**或**勿扰**专注模式时：刷太久、小模型、很久没动静、下班，这几种平常的关心先不叫。到了医院这种要紧的地方照叫。
- 点了**想独处**：接下来 4 小时，除了要紧的地方都不叫。
- 点了**想聊天**：直接叫醒 TA，你在"睡觉"状态也叫。冷却只算 15 分钟，每天上限照样算。
- **手机电量低**时，很久没动静不当真（多半是没电关机了）。
- TA 被叫醒时，简报里会多一行「她现在：在工作（9:02 开始）」「说想独处（到 15:00）」这样的话；小模型看的时候也会看到这一行。

每一条都跟第 6 步一样：一条自动化（或快捷指令）+ 一个「获取 URL 的内容」，网址、方法、头部都照 6.1 填，**只有请求体的字段不一样**。

### 9.1 换上新代码

照 4.3 把 `worker.js` 换成这个压缩包里的新版，点 **Deploy**。

> 怎么确认是新版：在编辑器里按 Ctrl+F 搜 `想独处`，搜得到就对了。管理页里也会多出一栏「她现在」。

叫醒说明（第 5 步那个大框）里不用手动加新的项，新版会自己补上默认值；刷新管理页就能看到 `mood`、`inactivity`、`work_end` 这三项。

**定时一定要有**：下班确认、很久没动静都靠 4.8 那个定时（`*/30 * * * *`）去查。没加过的照 4.8 加上；填过 `17 * * * *` 的改成 `*/30 * * * *`。

### 9.2 电量低于 20%

1. **自动化** → **＋** → 往下找 **电池电量** → 选 **降至低于**，拖到 **20%** → **立即运行** → 下一步。
2. 添加「获取 URL 的内容」，请求体：
   - `type` ＝ `battery_low`
   - `level` ＝ `20`
3. ▶ 试运行，看到 `"ok": true` 就成功了。

想让守门人知道"电量又够了"，可以再建一条：电池电量 → **升至高于** 30%，`type` ＝ `battery_ok`、`level` ＝ `30`。不建也行：守门人收到"开始充电"（6.3 那条）也会当电量回来了。

### 9.3 工作、勿扰、睡眠专注模式

**每个模式要建两条**：一条"打开时"、一条"关闭时"，跟 6.1、6.2 一样别勾在同一条里。先只做「工作」就够了，勿扰、睡眠想做再做。

1. **自动化** → **＋** → **专注模式** → 选 **工作** → 只勾 **开启时** → **立即运行** → 下一步。
2. 添加「获取 URL 的内容」，请求体：
   - `type` ＝ `focus_change`
   - `mode` ＝ `work`（写中文 `工作` 也行）
   - `active` ＝ `true`
3. 再建一条：专注模式 → 工作 → 只勾 **关闭时**，请求体一样，只把 `active` 改成 `false`。

勿扰、睡眠照着做，`mode` 分别写 `dnd`（或 `勿扰`）、`sleep`（或 `睡眠`）。

- 睡眠专注模式打开，守门人就当你**去睡了**，跟 6.3 的"就寝"一样；关掉就当**起床了**。6.3 已经做了就寝、起床那两条的，睡眠模式这两条可以不建。
- 别的模式（个人、健身、驾驶……）也能报，守门人会记下来、写进简报，但不会因为它们拦着不叫。

**下班**不用另外建：工作模式关掉、15 分钟内没再打开，守门人就记一笔"下班了，从几点起工作了几小时"。

### 9.4 心情（手动点的那种）

这条不是自动化，是一个**普通的快捷指令**，你想点的时候自己点：

1. 快捷指令底部 **快捷指令** 标签 → 右上角 **＋** → 名字改成「心情」。
2. 添加操作 → 搜 **列表** → 选 **从列表中选取**。点"列表"，填四行：`开心`、`低落`、`想独处`、`想聊天`（就这四个词，**一个字都别改**）。
3. 再添加「获取 URL 的内容」，网址、方法、头部照 6.1，请求体：
   - `type` ＝ `mood`
   - `mood` ＝ 点一下值的位置，选上面那步的蓝色变量 **所选项目**
   > 这里用蓝色变量是对的：这是你手动点的快捷指令，点的时候会有值。6.1 说的"别用蓝色变量"是指自动化。
4. 右上角 **ⓘ**（或分享按钮）→ **添加到主屏幕**。以后点主屏上的「心情」，选一个就报上去了。

也可以放进锁屏小组件，或者设置 → 辅助功能 → 触控 → **轻点背面** → 选这个快捷指令，敲两下手机背面就弹出来。

### 9.5 看状态对不对

管理页最上面多了一栏 **「她现在」**，写着守门人眼里你现在的样子，比如「在工作（09:02 开始），手机电量低（20%）」。打开、关掉专注模式，点一次心情，刷新页面看它有没有跟着变。

**「小模型和定时检查」**那一栏里，除了小模型，还会出现两种记录：
- **下班确认**：关了工作模式 15 分钟后的那次定时检查会记一笔（定时每 30 分钟一次，所以可能要等到 45 分钟后）。
- **没动静检查**：超过 3 小时没动静，先记"先等等"；下一次检查还是没动静，才记成一次"没动静"。

### 9.6 看几天，再决定要不要叫

很久没动静、下班这两种，**默认只记不叫**（`wake` 是 `false`）。先用几天，看管理页里记的准不准：

- 没动静的那几次，你是真的没碰手机，还是快捷指令漏报了？
- 下班时间对不对？

觉得准了，再把叫醒说明里的 `"wake": false` 改成 `true`，保存。改之前也可以先在 Aru 里问问 TA：你下班的时候，TA 想不想被叫醒？

### 9.7 更多小报告：截屏、通知、闹钟、助眠、Wi-Fi、运动、CarPlay、钱包、声音（以 iOS 27.2 为例）

这 9 种**默认都只记下来、不叫醒 TA**，等 TA 下次因为别的事被叫醒时，在简报里看得到你这几个小时做了什么。想让哪一种叫醒 TA，在叫醒说明里把它打开（见本节最后「改开关」），比如**关掉闹钟**（TA 说早安）、**敲门、门铃、警报、婴儿哭这几种声音**。打开了也照样要过底线：
- 凌晨 1–5 点不叫；
- 你在睡觉、开着工作或勿扰、说了想独处时不叫；
- 冷却和每天上限照算。

每种是做什么的、TA 能知道什么、建议先上哪几种，见 `方案.md`。**不用全做**，挑想要的几条建就行。

**先换代码**：照 4.3 把 `worker.js` 换成新版，点 **Deploy**。在编辑器里按 Ctrl+F 搜 `wind_down`，搜得到就是新版。刷新管理页，叫醒说明里会多出一组 `reports`。

**每一条的做法都跟 6.1 一样**：自动化 → ＋ → 选触发器 → **立即运行**、关掉"运行时通知" → 下一步 → 添加「获取 URL 的内容」，网址、方法、头部照 6.1 填，**只有请求体的字段不一样**。下面每种只写不一样的地方。请求体里的值都**直接打字**，别用蓝色变量（除了特别说明的）。

#### 截屏

- 触发器：**App** → **截屏** →（已保存截屏时）
- 请求体：`type` ＝ `screenshot`
- 不用额外权限。截了什么不会上传；5 分钟内连着截几张，守门人只记一条。

#### 收到某个 App 的通知

- 触发器：**App** → **通知** → 选一个 App（比如 微信）→（收到来自这个 App 的通知时）
- 请求体：
  - `type` ＝ `notify`
  - `app` ＝ `微信`（直接打字，跟你选的 App 一样）
- **千万别把"通知内容""通知标题"这些蓝色变量填进请求体。** 守门人只要 App 名字。就算填进去了，它也会在存之前把多出来的字段扔掉，但最好一开始就别填。
- 每个 App 单独建一条。同一个 App 10 分钟内只记一条。
- 消息多的 App 会很吵，建议先不建，或者只给一两个重要的 App 建。

#### 关掉闹钟

- 触发器：**日常事务** → **闹钟** → 选 **停止时** →（任意闹钟，或者只选早上那个）
- 请求体：`type` ＝ `alarm_stop`
- 守门人会把你当成**醒了**。默认只记下来；想让 TA 一起来说早安，把 `alarm_stop` 的 `wake` 打开。凌晨 1–5 点关的闹钟不叫。
- 6.3 里已经用"闹钟停止时"报 `wake_up` 的，把那条删掉、换成这条，或者干脆不建这条，**别两条都留**。

#### 助眠开始

- 触发器：**日常事务** → **睡眠** → **助眠开始时**
- 请求体：`type` ＝ `wind_down`
- 第一次要先在 **健康** App → **睡眠** 里设好作息、打开"助眠"，不然这个触发器不会响。
- 6.3 的"去睡了"（`sleep`）用的也是这个触发器，**二选一**：
  - 想让守门人把你当成在睡觉、之后不叫 TA，用 `sleep`；
  - 只想让 TA 知道你准备睡了，用 `wind_down`。

#### 连上家里的 Wi-Fi

- 触发器：**连接状态** → **无线局域网** → 选你家的网络 →（加入时）
- 请求体：
  - `type` ＝ `wifi_join`
  - `place` ＝ `家`（你自己起的名字。写"家"的话，简报里会写成"连上了家里的 Wi-Fi"）
- 每个网络建一条，比如公司的那条 `place` 写 `公司`。网络名和密码都不会报上去。
- 第一次可能会问权限，按提示允许就行。

#### 开始运动

- 触发器：**App** → **体能训练** → 选运动种类 →（开始时）
- 请求体：
  - `type` ＝ `workout`
  - `kind` ＝ `跑步`（可以不填，填了简报里写"开始运动了（跑步）"）
- 要 Apple Watch 或手机上的「体能训练」开始一次运动才会响。开着"健身"专注模式、9.3 也报了的话，这条可以不建。

#### CarPlay 上车、下车

**要建两条**：一条连接时、一条断开时，别勾在同一条里。
- 触发器：**连接状态** → **CarPlay 车载** → 只勾 **连接时**
- 请求体：
  - `type` ＝ `carplay`
  - `on` ＝ `true`
- 再建一条：只勾 **断开时**，`on` 改成 `false`。
- 连着 CarPlay 的时候，管理页"她现在"会写"在车上"，TA 被叫醒时也看得到，知道你在开车、别找你说话。

#### 钱包刷卡

- 触发器：**App** → **钱包** → 选卡 →（轻触卡片或凭证时）
- 请求体：
  - `type` ＝ `wallet`
  - `card` ＝ `地铁卡`（你自己起的名字）
- **只给交通卡、门禁卡这种建，银行卡别建。** 也别把金额、商户这些蓝色变量填进来；就算填了，守门人也只留卡名。
- 每张卡单独建一条，`card` 写那张卡的名字。

#### 声音识别（门铃、敲门……）

1. 第一次要先打开：**设置** → **辅助功能** → **声音识别** → 打开 → **声音** → 勾上想识别的（门铃、敲门、警报、婴儿哭……）。
   - 手机是自己在本机上听的，不录音、不上传，也不会弹录音面板。
   - **别把它当报警器用**：苹果也说了，声音识别在紧急情况下不可靠。
2. 触发器：**环境** → **声音识别** → 选一种声音（比如 敲门）
3. 请求体：
   - `type` ＝ `sound`
   - `sound` ＝ `敲门`（直接打中文：`门铃`、`敲门`、`警报`、`婴儿哭`、`流水`、`狗叫`、`猫叫`……）
4. 每种声音单独建一条，`sound` 写跟触发器一样的那种。

- **打开 `sound` 的 `wake` 以后会叫醒 TA 的**：门铃、敲门、警报、婴儿哭（写"火警"也算警报）。默认没打开，都只记下来。
- **打开了也只记不叫的**：狗叫、猫叫、流水，还有别的声音。
- 同一种声音 3 分钟内只记一条。

#### 在叫醒说明里改开关（`reports` 那一组）

```
"reports": {
  "night_quiet": true,
  "alarm_stop": { "wake": false },
  "sound": { "wake": false, "wake_kinds": ["门铃", "敲门", "警报", "婴儿哭"], "dedupe_min": 3 },
  "notify": { "wake": false, "dedupe_min": 10 },
  "screenshot": { "wake": false, "dedupe_min": 5 },
  ……
}
```

- `wake`：这一种能不能叫醒 TA。**默认 9 种都是 `false`**（只记不叫）；想要哪种叫醒就改成 `true`，照样要过底线。最常开的是 `alarm_stop`（早安）和 `sound`（有人敲门）。
- `wake_kinds`：哪几种声音叫醒。比如不想被婴儿哭叫醒，就把 `"婴儿哭"` 删掉。
- `dedupe_min`：几分钟内同一种只记一条。改成 `0` 就不防刷屏。
- `night_quiet`：`true` 时，凌晨（`late_night` 的 `from`～`to` 点）小报告一律不叫醒。

**试一下**：建好「关掉闹钟」那条、并把 `alarm_stop` 的 `wake` 改成 `true` 以后，设一个一分钟后的闹钟，响了点停止。
- 管理页「最近 6 小时收到的事」里会多一行 `alarm_stop`；
- 「叫醒记录」里会多一行 `report_alarm_stop`。离上次叫醒不到 60 分钟的话，这一行会写"挡下：冷却"，这是正常的。

### 要先知道的（第 9 步）

- **"没动静"只是"没收到报告"**：快捷指令有时候会漏跑，没网也报不上来。所以守门人要连着两次检查都没动静才算，电量低的时候也不当真。只做了小红书一个 App 的话，你在刷别的 App 它也看不到，会当成没动静，这种情况就别打开 `inactivity.wake`。
- **心情只记你自己点的**，守门人不会去猜你开不开心。

## 排错

| 看到什么 | 多半是 |
|---|---|
| 管理页打不开（转圈、连不上） | 用的是 `workers.dev` 地址，国内被挡了 → 做 4.6 换成自己的域名 |
| "还没绑定 D1 数据库" | 4.4 没做，或变量名不是 `DB` |
| "还没设 ADMIN_TOKEN / EVENT_TOKEN" | 密钥名字拼错（比如多了个字母），或者加了没点 Deploy |
| "管理口令不对" | 网址 `#key=` 后面那串（或页面上粘贴的）跟 `ADMIN_TOKEN` 不一样；口令里有符号就换成纯字母数字。v2.2 起 `?key=` 不再管用，要换成 `#key=` |
| "事件口令不对" | 快捷指令头部的口令不对，或 `Bearer` 后面没空格 |
| 只回"口令不对"四个字 | 线上还是旧代码：重新贴代码，点 **Deploy** |
| "不认识的 type" | 快捷指令里 `type` 的值拼错了 |
| 刷了很久也没叫醒，记录里只有 `app_open` / `app_close` 没有 App 名字 | 快捷指令请求体里少了 `app`，或者值用了蓝色变量（自动化跑的时候是空的）→ 改成直接打字（6.4） |
| 测试敲门显示"失败：…redirect…" | 守门人代码太旧，换新版 |
| 测试敲门显示"失败：HTTP 4xx" | 凭证不对，或者那个触发器已经删了 → 重新导出，换 `WAKE_BUNDLE` |
| 敲门成功了，TA 却总说"是测试" | 触发器名字带了"测试"，或者刚连着测了好多次 → 换个正式名字的触发器 |
| 手机连不上 Host | 跟电脑同一个 Wi-Fi 下点「检查」；Windows 防火墙（2.1）；iPhone 设置 → Aru → 本地网络打开 |
| Cloudflare 让你"去注册商改域名服务器" | **先停下问人**，多半是在别的账号里又加了一次域名 |
| 小模型那一栏一直是"还没看过" | `model.enabled` 没改成 `true`；Cron（4.8）没加；或者现在不在 `from`～`to` 的时间里；你在睡觉状态（快捷指令报了"就寝"还没报"起床"）也不看 |
| 小模型显示"出错：没绑定 Workers AI" | 7.2 没做、变量名不是 `AI`、没点 Deploy |
| 小模型一直"出错"，带着 `410`、`5028` 或 `Gone`；或者换了模型以后老是"没回 JSON" | 模型被 Cloudflare 下架了（原来默认的千问 2026-11-20 下架）。照第 7 步开头那段换新代码（只改 `name` 不行） |
| 小模型说"想叫"，但没敲门 | 看那一行下面的灰字：被底线挡下了（冷却、每天上限、小模型自己的上限）；也可能你开着工作/勿扰模式、说了想独处 |
| 试运行回"focus_change 要带 mode / active" | 请求体少了 `mode` 或 `active` 那一行，或者字段名拼错 |
| 试运行回"active 要写 true 或 false" | `active` 的值写成了别的字。打开写 `true`，关闭写 `false` |
| 试运行回"mood 要是 …" | 列表里的四个词改过了。只能是 开心、低落、想独处、想聊天（或者英文 happy、low、alone、need_company） |
| 「她现在」一直写着"在工作" | "关闭时"那条没建，或者 `active` 没改成 `false` |
| 点了想聊天没叫醒 | 看叫醒记录：离上次叫醒不到 15 分钟、今天叫满了；或者叫醒说明里 `mood.request` 是 `false` |

## 隐私和安全

- 守门人记的是你的作息、位置、App 使用，都存在**你自己的** Cloudflare D1 里；做了 4.8 的定时清理，14 天以前的会自动删掉（v2.2 起叫醒 TA 时的简报也一起删）。
- 小模型用 Workers AI 的话，判断由 Cloudflare 来做，不会发去别家（留存照 Cloudflare 的条款）；换成别家（7.7）的话，动静记录会发给那家，对方可能会保存。
- 送进 Aru 的简报用你的钥匙加密，你电脑上的 Host 和 Aru 官方的中继都读不到内容。如果你另外配了 `PUSH_URL`（ntfy 这类推送），那条推送是**明文**的。
- **三样东西别给任何人**：管理口令、事件口令、发送凭证。截图前先遮住。
- 不想用了：在 Aru 里删掉外部触发器，在 Cloudflare 里删掉 `knock` 这个 Worker 和 D1 数据库，再删掉快捷指令里的自动化。

## 给带你装的 AI

如果你是 AI，正在照这份教程带一个人搭 knock 守门人，请照下面做：

**先问清楚再开始**
- 先问：用的是 Windows 还是 Mac；有没有自己的域名；Aru 里能不能看到「协作者 → 主动 → 外部触发」；电脑上的 Aru Host 装好没有。缺哪样就先如实告诉对方，从对应的那一步开始，别跳步。
- 小模型一直报错、带着 `410` 或 `5028` 的：是原来默认的千问模型 2026-11-20 被 Cloudflare 下架了，照第 7 步开头那段处理，别的不用动。
- 已经装好、只是要接小模型的，直接从第 7 步开始；只是要加电量、专注模式、心情的，从第 9 步开始（先做 9.1 换代码）。

**一次只带一步**
- 说清楚这一步做什么、为什么，等对方说做好了、并且看到了这一步写的"成了的样子"，再往下。不要一口气把几步全丢给对方。
- 对方多半没用过命令行，也不熟 Cloudflare：说清楚点哪里、在哪个窗口、粘贴后按什么。名字要一模一样的地方（`DB`、`AI`、`EVENT_TOKEN`、`ADMIN_TOKEN`、`WAKE_BUNDLE`）要特别提醒；「Save version 不是 Deploy」也要提醒。

**口令和凭证：绝不进对话**
- 不向对方要管理口令、事件口令、Aru 导出的发送凭证，也不让对方把带 `#key=`（或旧的 `?key=`）的网址、快捷指令里的 Authorization 贴进对话。哪怕是为了帮忙核对也不要。
- 要看截图时，先提醒对方遮住口令和凭证（浏览器地址栏也要裁掉）。万一已经发出来了，告诉对方：口令去 Cloudflare 换一个新的，凭证去 Aru 里删掉那个触发器重建。
- 要核对口令有没有抄错，让对方自己对比前四个、后四个字。

**界面对不上时别编**
- Cloudflare、Aru、快捷指令的界面都会改版，这份教程的按钮名可能对不上。对不上时请对方截图（遮住口令）或描述屏幕上的字，照实际看到的带，不要凭印象编菜单位置。
- Cloudflare 提示"去域名注册商改域名服务器（NS）"时，先停下来问清楚：多半是在另一个账号里又加了一次域名，照做会让域名整个断掉。

**没有原版代码时别补**
- 这份教程本身不含守门人代码。对方手上要是只有教程、没有压缩包里的 `worker.js`，请告诉对方去找给教程的人要原版压缩包（作者 White-ting），**不要照着教程自己写一份守门人代码**，也不要从网上找别人改过的版本。管理页最底下一行写着版本号和 White-ting 的，才是原版搭出来的。

**卡住了**
- 先对照「排错」那张表。
- 管理页的「叫醒记录」「小模型」两栏会写原因（"挡下：……""出错：……"），先请对方看那里写了什么。
